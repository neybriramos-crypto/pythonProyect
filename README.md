Sistema de Inventario en Python
Aplicación de escritorio desarrollada en Python para la gestión de inventario de productos, utilizando una interfaz gráfica moderna y almacenamiento en archivos CSV.

Características
• Creación automática de base de datos (inventario.csv)
• Operaciones CRUD completas:
• Crear productos
• Leer y mostrar productos
• Actualizar productos
• Eliminar productos
• ID autogenerado para cada producto
• Interfaz gráfica moderna con CustomTkinter
• Validación básica de datos

Tecnologías utilizadas
• Python 3.x
• Librerias:
    • CustomTkinter (interfaz gráfica)
    • Tkinter (Treeview para tabla)
    • CSV (almacenamiento de datos)
